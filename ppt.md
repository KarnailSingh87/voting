# Aadhaar Voting System

---

## Project Features

- Secure voter authentication (Aadhaar, OTP)
- Admin dashboard for election management
- Voter dashboard for ballot casting
- Query system for user support
- Real-time results and history

---

## Architecture

- Frontend: React + Vite + Tailwind
- Backend: Node.js + Express + MongoDB
- Admin & Voter portals
- REST API endpoints

---

## Query Management

- Users can raise queries from dashboard
- Admins view and manage queries

---

## Tech Stack

- Node.js, Express, MongoDB
- React, Vite, Tailwind CSS
- Cypress for testing
