# 🔗 Blockchain Integration Guide for Voting System

## Overview

Blockchain integration will enhance your voting system with:
- ✅ **Immutability** - Votes cannot be altered after casting
- ✅ **Transparency** - Voter can verify their vote was recorded
- ✅ **Decentralization** - No single point of failure
- ✅ **Audit Trail** - Complete history visible to stakeholders
- ✅ **Security** - Cryptographic verification

## Technology Stack Options

### **Option 1: Ethereum (Recommended for University)**
```
Pros:
✅ Most mature ecosystem
✅ Large developer community
✅ Proven security
✅ Multiple client libraries (ethers.js, web3.js)
✅ Smart contracts support
✅ Test networks available (Sepolia, Goerli)

Cons:
❌ Gas fees (though low on testnet)
❌ Requires cryptocurrency wallet
❌ More complex setup

Best for: Serious voting system with high trust requirements
```

### **Option 2: Hyperledger Fabric**
```
Pros:
✅ Private/permissioned (only authorized voters)
✅ No cryptocurrency needed
✅ Enterprise-grade
✅ High throughput
✅ Zero gas fees

Cons:
❌ More complex setup
❌ Smaller community
❌ Harder to get started

Best for: Large organizations, government voting
```

### **Option 3: Polygon (L2 Solution)**
```
Pros:
✅ Ethereum-compatible (same tools)
✅ Very low gas fees (much cheaper)
✅ Faster transactions
✅ Easier for universities

Cons:
❌ Still requires crypto wallet
❌ Less decentralized than Ethereum

Best for: Cost-conscious implementations
```

### **Option 4: Self-Hosted Blockchain (Hardhat/Ganache)**
```
Pros:
✅ Full control
✅ No fees
✅ Private network
✅ Fast development

Cons:
❌ Centralized (defeats blockchain purpose)
❌ No external verification
❌ Harder to audit

Best for: Learning/prototyping, not production
```

#### **1.2 Create Smart Contract**

Create `backend/contracts/VotingContract.sol`:

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.0;

contract SecureVoting {
    // Structs
    struct Election {
        uint256 id;
        string title;
        uint256 startTime;
        uint256 endTime;
        bool ended;
        mapping(address => bool) voters;
        mapping(uint256 => Candidate) candidates;
        uint256 candidateCount;
    }

    struct Candidate {
        uint256 id;
        string name;
        uint256 voteCount;
    }

    struct VoteRecord {
        bytes32 voteHash;
        uint256 electionId;
        uint256 candidateId;
        uint256 timestamp;
    }

    // State Variables
    address public admin;
    uint256 public electionCount = 0;
    
    mapping(uint256 => Election) public elections;
    mapping(bytes32 => VoteRecord) public voteRecords;
    mapping(bytes32 => bool) public voteHashes; // For uniqueness
    
    // Events
    event ElectionCreated(uint256 indexed electionId, string title);
    event VoteCast(
        bytes32 indexed voteHash,
        uint256 indexed electionId,
        uint256 indexed candidateId,
        uint256 timestamp
    );
    event ElectionEnded(uint256 indexed electionId);

    // Modifiers
    modifier onlyAdmin() {
        require(msg.sender == admin, "Only admin can call this");
        _;
    }

    modifier electionActive(uint256 _electionId) {
        require(block.timestamp >= elections[_electionId].startTime, "Election not started");
        require(block.timestamp <= elections[_electionId].endTime, "Election ended");
        require(!elections[_electionId].ended, "Election finished");
        _;
    }

    // Constructor
    constructor() {
        admin = msg.sender;
    }

    // Create Election
    function createElection(
        string memory _title,
        uint256 _startTime,
        uint256 _endTime
    ) public onlyAdmin returns (uint256) {
        require(_endTime > _startTime, "Invalid time range");
        
        uint256 electionId = electionCount;
        elections[electionId].id = electionId;
        elections[electionId].title = _title;
        elections[electionId].startTime = _startTime;
        elections[electionId].endTime = _endTime;
        elections[electionId].ended = false;
        elections[electionId].candidateCount = 0;

        electionCount++;
        emit ElectionCreated(electionId, _title);
        
        return electionId;
    }

    // Add Candidate to Election
    function addCandidate(
        uint256 _electionId,
        string memory _name
    ) public onlyAdmin {
        require(_electionId < electionCount, "Election not found");
        
        uint256 candidateId = elections[_electionId].candidateCount;
        elections[_electionId].candidates[candidateId] = Candidate({
            id: candidateId,
            name: _name,
            voteCount: 0
        });
        elections[_electionId].candidateCount++;
    }

    // Cast Vote
    function castVote(
        uint256 _electionId,
        uint256 _candidateId,
        bytes32 _voteHash
    ) public electionActive(_electionId) {
        require(_candidateId < elections[_electionId].candidateCount, "Candidate not found");
        require(!elections[_electionId].voters[msg.sender], "Already voted");
        require(!voteHashes[_voteHash], "Vote hash already used");

        // Mark voter as voted
        elections[_electionId].voters[msg.sender] = true;

        // Increment vote count
        elections[_electionId].candidates[_candidateId].voteCount++;

        // Record vote
        voteRecords[_voteHash] = VoteRecord({
            voteHash: _voteHash,
            electionId: _electionId,
            candidateId: _candidateId,
            timestamp: block.timestamp
        });
        voteHashes[_voteHash] = true;

        // Emit event
        emit VoteCast(_voteHash, _electionId, _candidateId, block.timestamp);
    }

    // Get Election Results
    function getResults(uint256 _electionId)
        public
        view
        returns (Candidate[] memory)
    {
        require(_electionId < electionCount, "Election not found");
        
        Candidate[] memory results = new Candidate[](elections[_electionId].candidateCount);
        
        for (uint256 i = 0; i < elections[_electionId].candidateCount; i++) {
            results[i] = elections[_electionId].candidates[i];
        }
        
        return results;
    }

    // Get Vote Record
    function getVoteRecord(bytes32 _voteHash)
        public
        view
        returns (VoteRecord memory)
    {
        return voteRecords[_voteHash];
    }

    // Check if voter already voted
    function hasVoted(uint256 _electionId, address _voter)
        public
        view
        returns (bool)
    {
        return elections[_electionId].voters[_voter];
    }

    // End Election (only admin)
    function endElection(uint256 _electionId) public onlyAdmin {
        require(_electionId < electionCount, "Election not found");
        elections[_electionId].ended = true;
        emit ElectionEnded(_electionId);
    }
}
```

### **Phase 3: Backend Integration**

#### **3.1 Create Blockchain Service**

Create `backend/services/blockchainService.js`:

```javascript
import ethers from 'ethers';
import fs from 'fs';
import VotingABI from '../contracts/VotingContract.json' assert { type: 'json' };

class BlockchainService {
  constructor() {
    this.provider = new ethers.JsonRpcProvider(
      process.env.SEPOLIA_RPC_URL || 'http://localhost:8545'
    );
    
    this.signer = new ethers.Wallet(
      process.env.PRIVATE_KEY || '',
      this.provider
    );
    
    this.contractAddress = process.env.VOTING_CONTRACT_ADDRESS;
    this.contract = new ethers.Contract(
      this.contractAddress,
      VotingABI.abi,
      this.signer
    );
  }

  // Create election on blockchain
  async createElection(title, startTime, endTime) {
    try {
      const tx = await this.contract.createElection(title, startTime, endTime);
      const receipt = await tx.wait();
      
      return {
        success: true,
        txHash: receipt.hash,
        blockNumber: receipt.blockNumber,
        electionId: receipt.events[0].args.electionId.toString()
      };
    } catch (error) {
      console.error('Blockchain election creation error:', error);
      return { success: false, error: error.message };
    }
  }

  // Add candidate on blockchain
  async addCandidate(electionId, candidateName) {
    try {
      const tx = await this.contract.addCandidate(electionId, candidateName);
      const receipt = await tx.wait();
      
      return {
        success: true,
        txHash: receipt.hash,
        blockNumber: receipt.blockNumber
      };
    } catch (error) {
      console.error('Blockchain candidate creation error:', error);
      return { success: false, error: error.message };
    }
  }

  // Cast vote on blockchain
  async castVote(electionId, candidateId, voteHash) {
    try {
      const tx = await this.contract.castVote(electionId, candidateId, voteHash);
      const receipt = await tx.wait();
      
      return {
        success: true,
        txHash: receipt.hash,
        blockNumber: receipt.blockNumber,
        voteHash: voteHash,
        timestamp: receipt.blockTimestamp
      };
    } catch (error) {
      console.error('Blockchain vote casting error:', error);
      return { success: false, error: error.message };
    }
  }

  // Get election results
  async getResults(electionId) {
    try {
      const results = await this.contract.getResults(electionId);
      
      return {
        success: true,
        results: results.map(candidate => ({
          id: candidate.id.toString(),
          name: candidate.name,
          voteCount: candidate.voteCount.toString()
        }))
      };
    } catch (error) {
      console.error('Blockchain results error:', error);
      return { success: false, error: error.message };
    }
  }

  // Verify vote on blockchain
  async verifyVote(voteHash) {
    try {
      const voteRecord = await this.contract.getVoteRecord(voteHash);
      
      return {
        success: true,
        verified: voteRecord.voteHash === voteHash,
        electionId: voteRecord.electionId.toString(),
        candidateId: voteRecord.candidateId.toString(),
        timestamp: new Date(voteRecord.timestamp.toNumber() * 1000)
      };
    } catch (error) {
      console.error('Blockchain verification error:', error);
      return { success: false, error: error.message };
    }
  }

  // Check if voter already voted
  async hasVoted(electionId, voterAddress) {
    try {
      const voted = await this.contract.hasVoted(electionId, voterAddress);
      return { success: true, hasVoted: voted };
    } catch (error) {
      console.error('Blockchain vote check error:', error);
      return { success: false, error: error.message };
    }
  }

  // Get contract address
  getContractAddress() {
    return this.contractAddress;
  }

  // Get network info
  async getNetworkInfo() {
    try {
      const network = await this.provider.getNetwork();
      const blockNumber = await this.provider.getBlockNumber();
      
      return {
        success: true,
        chainId: network.chainId,
        chainName: network.name,
        blockNumber: blockNumber
      };
    } catch (error) {
      console.error('Blockchain network info error:', error);
      return { success: false, error: error.message };
    }
  }
}

export default new BlockchainService();
```

#### **3.2 Update Vote Routes**

Modify `backend/routes/voteRoutes.js`:

```javascript
import express from 'express';
import blockchainService from '../services/blockchainService.js';
import voterAuth from '../middleware/voterAuth.js';
import Vote from '../models/Vote.js';
import Voter from '../models/Voter.js';
import Candidate from '../models/Candidate.js';
import Election from '../models/Election.js';

const router = express.Router();

router.post('/cast', voterAuth, async (req, res) => {
  try {
    const { candidateId, electionId } = req.body;
    
    // Get MongoDB data first
    const candidate = await Candidate.findById(candidateId);
    const election = await Election.findById(electionId);
    const voter = await Voter.findById(req.voter.id);

    if (!candidate || !election) {
      return res.status(404).json({ message: 'Not found' });
    }

    // Check if already voted
    if (voter.history?.some(h => h.electionId.toString() === electionId)) {
      return res.status(409).json({ message: 'Already voted' });
    }

    // Generate vote hash
    const voteHash = crypto
      .createHash('sha256')
      .update(`${voter._id}-${candidate._id}-${Date.now()}-${Math.random()}`)
      .digest('hex');

    // 1. Record in MongoDB first
    const vote = await Vote.create({
      voteHash,
      election: electionId,
      candidate: candidateId,
      timestamp: new Date()
    });

    // 2. Record on blockchain (parallel or sequential)
    const blockchainResult = await blockchainService.castVote(
      electionId,
      candidateId,
      '0x' + voteHash // Format for blockchain
    );

    if (!blockchainResult.success) {
      console.warn('Blockchain recording failed:', blockchainResult.error);
      // Still return success to user, blockchain is backup
    }

    // 3. Update voter
    voter.hasVoted = true;
    voter.history.push({
      electionId,
      voteHash,
      blockchainTxHash: blockchainResult.txHash, // Store blockchain tx
      timestamp: new Date()
    });
    await voter.save();

    // Update candidate count
    candidate.voteCount += 1;
    await candidate.save();

    return res.json({
      success: true,
      message: 'Vote cast successfully',
      voteHash,
      blockchainTxHash: blockchainResult.txHash,
      blockchainBlockNumber: blockchainResult.blockNumber,
      confirmationId: voteHash
    });
  } catch (error) {
    console.error('Vote cast error:', error);
    res.status(500).json({ message: 'Server error' });
  }
});

// Verify vote on blockchain
router.get('/verify/:voteHash', async (req, res) => {
  try {
    const result = await blockchainService.verifyVote('0x' + req.params.voteHash);
    
    if (!result.success) {
      return res.status(400).json({ message: result.error });
    }

    return res.json({
      success: true,
      verified: result.verified,
      timestamp: result.timestamp,
      message: result.verified ? 'Vote verified on blockchain' : 'Vote not found'
    });
  } catch (error) {
    res.status(500).json({ message: 'Server error' });
  }
});

// Get blockchain results
router.get('/results/:electionId/blockchain', async (req, res) => {
  try {
    const result = await blockchainService.getResults(req.params.electionId);
    
    if (!result.success) {
      return res.status(400).json({ message: result.error });
    }

    return res.json({
      success: true,
      results: result.results,
      source: 'blockchain',
      immutable: true
    });
  } catch (error) {
    res.status(500).json({ message: 'Server error' });
  }
});

export default router;
```

```javascript
import React, { createContext, useState, useCallback } from 'react';
import { ethers } from 'ethers';

export const BlockchainContext = createContext();

export const BlockchainProvider = ({ children }) => {
  const [account, setAccount] = useState(null);
  const [provider, setProvider] = useState(null);
  const [isConnected, setIsConnected] = useState(false);
  const [network, setNetwork] = useState(null);

  // Connect wallet
  const connectWallet = useCallback(async () => {
    try {
      if (!window.ethereum) {
        throw new Error('MetaMask not installed');
      }

      const provider = new ethers.BrowserProvider(window.ethereum);
      await provider.send('eth_requestAccounts', []);

      const signer = await provider.getSigner();
      const address = await signer.getAddress();

      const network = await provider.getNetwork();

      setAccount(address);
      setProvider(provider);
      setNetwork(network);
      setIsConnected(true);

      return { address, network };
    } catch (error) {
      console.error('Wallet connection failed:', error);
      return { error: error.message };
    }
  }, []);

  // Disconnect wallet
  const disconnectWallet = useCallback(() => {
    setAccount(null);
    setProvider(null);
    setNetwork(null);
    setIsConnected(false);
  }, []);

  // Verify vote on blockchain
  const verifyVoteOnBlockchain = useCallback(
    async (voteHash) => {
      try {
        if (!provider) {
          throw new Error('Wallet not connected');
        }

        // Call backend verification endpoint
        const response = await fetch(`/api/vote/verify/${voteHash}`);
        const data = await response.json();

        return data;
      } catch (error) {
        console.error('Vote verification failed:', error);
        return { success: false, error: error.message };
      }
    },
    [provider]
  );

  return (
    <BlockchainContext.Provider
      value={{
        account,
        provider,
        isConnected,
        network,
        connectWallet,
        disconnectWallet,
        verifyVoteOnBlockchain
      }}
    >
      {children}
    </BlockchainContext.Provider>
  );
};
```

#### **4.3 Update Ballot Component**

Create `frontend/src/pages/voting/BallotWithBlockchain.jsx`:

```javascript
import { useState, useContext } from 'react';
import { BlockchainContext } from '../../context/BlockchainContext';
import axios from '../../utils/axios';

const BallotWithBlockchain = ({ electionId }) => {
  const { account, connectWallet, verifyVoteOnBlockchain } = useContext(BlockchainContext);
  const [selectedCandidate, setSelectedCandidate] = useState('');
  const [voteCast, setVoteCast] = useState(false);
  const [voteHash, setVoteHash] = useState('');
  const [blockchainStatus, setBlockchainStatus] = useState(null);

  const handleCastVote = async () => {
    try {
      // Cast vote on backend
      const response = await axios.post('/api/vote/cast', {
        electionId,
        candidateId: selectedCandidate
      });

      const { voteHash, blockchainTxHash } = response.data;
      setVoteHash(voteHash);
      setBlockchainStatus({
        txHash: blockchainTxHash,
        status: 'pending'
      });

      // Verify on blockchain
      const verifyResult = await verifyVoteOnBlockchain(voteHash);
      setBlockchainStatus({
        txHash: blockchainTxHash,
        status: 'verified',
        verified: verifyResult.verified,
        timestamp: verifyResult.timestamp
      });

      setVoteCast(true);
    } catch (error) {
      console.error('Vote casting failed:', error);
    }
  };

  if (voteCast) {
    return (
      <div className="success-container">
        <h2>Vote Cast Successfully!</h2>
        <p>Your vote has been recorded on both database and blockchain.</p>

        <div className="blockchain-verification">
          <h3>Blockchain Verification</h3>
          <p>Vote Hash: <code>{voteHash}</code></p>
          
          {blockchainStatus?.txHash && (
            <p>
              Transaction: 
              <a 
                href={`https://sepolia.etherscan.io/tx/${blockchainStatus.txHash}`}
                target="_blank"
                rel="noopener noreferrer"
              >
                {blockchainStatus.txHash.slice(0, 10)}...
              </a>
            </p>
          )}

          <p className={blockchainStatus?.verified ? 'verified' : 'pending'}>
            Status: {blockchainStatus?.status}
          </p>

          {blockchainStatus?.timestamp && (
            <p>Timestamp: {blockchainStatus.timestamp}</p>
          )}
        </div>

        <button onClick={() => window.location.href = '/dashboard'}>
          Return to Dashboard
        </button>
      </div>
    );
  }

  return (
    <div className="ballot-container">
      {/* Wallet Connection */}
      <div className="wallet-section">
        {account ? (
          <p>Connected: {account.slice(0, 6)}...{account.slice(-4)}</p>
        ) : (
          <button onClick={connectWallet}>
            Connect Wallet (Optional)
          </button>
        )}
      </div>

      {/* Candidate Selection */}
      <div className="candidates-section">
        {/* ... candidate selection UI ... */}
      </div>

      {/* Cast Vote */}
      <button
        onClick={handleCastVote}
        disabled={!selectedCandidate}
        className="cast-vote-button"
      >
        Cast Vote
      </button>
    </div>
  );
};

export default BallotWithBlockchain;
```
